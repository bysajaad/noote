Slash commands

24 block commands — headings, todos, tables, code fences, GFM alerts and more. Filter by label or alias: /tab and /table both hit Table.

Enter continues todos, bullets and numbered lists — auto-incrementing as it goes. Double Enter exits the list, just like a WYSIWYG editor.

RTL in VS Code's Markdown editors

VS Code's new WYSIWYG Markdown Editor has no RTL support yet — Arabic, Hebrew and Persian paragraphs are laid out left-to-right. Noote keeps you in the native text editor, which renders RTL runs in the correct reading order, and the Markdown preview shows correct bidi order.
